# RTO code table

`rto_codes.csv` is derived from
[List of Regional Transport Office districts in India](https://en.wikipedia.org/wiki/List_of_Regional_Transport_Office_districts_in_India)
by Wikipedia contributors, under the
[Creative Commons Attribution-ShareAlike 4.0 License](https://creativecommons.org/licenses/by-sa/4.0/).
The table was reformatted, with one row per RTO code, and lightly cleaned. Its changes may be
shared only under the same license. This file is not covered by VRPR's MIT License.

Rebuild it with `python scripts/build_rto_codes.py`. Wikipedia can be incomplete or out of date,
so treat an RTO's office and area as a guide, not an official record.
